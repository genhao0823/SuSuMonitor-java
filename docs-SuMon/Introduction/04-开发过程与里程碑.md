### 关键教训:测试为什么没拦住真实 Bug

| 场景 | 单测全绿原因 | 真实环境炸在哪 |
|---|---|---|
| 告警规则 Mapper 500 | Controller/Service 测试全部 mock Mapper,SQL 从未真实执行 | MyBatis 参数绑定只在 SQL 真正执行时校验(`#{rule.xxx}` 缺 @Param) |
| 告警记录插入失败 | 同上 | H2 MySQL mode 参数绑定行为与真实 MySQL 不同 |
| 告警恢复后不重触发 | 测试模拟的是"设计意图"(mock 状态机返回值)而非真实数据流 | 状态机实现与设计脱节(置 0 而非删行) |

**结论:真实验收不可替代** —— 所以后期建立了"隔离 MySQL 验证库 + 真实 Broker + 真实浏览器"的验收体系。

## 三、性能基线(MVP-9,`bench-alert-chain.mjs`)

链路口径:`metrics.report` → MySQL 事务 → AFTER_COMMIT → 评估 → `metrics.update`/`alert.push` 到浏览器收到。

| 场景 | p50(ms) | p95(ms) | 结论 |
|---|---|---|---|
| S1 单服务器 1 规则 | 23.74(metrics.update) | 33.18 | 基线 |
| S2 100 规则不越界 | 68.62 | 88.81 | **规则数放大 +45ms**:每条规则一次 SQL 往返(100 次 selectByRuleAndServer),评估计算占比极小 → 优化方向明确 |
| S3 10 Agent 并发 | 12.51 | 16.03 | 19.67/s 线性放大,0 错误帧 |
| S4 持续越界 30s | 21.51 | 30.66 | 状态机去重正确:1 record / 1 push |
| S5 恢复后再次越界 ×10 | 20.15(alert.push) | 22.28 | 10 records,正确 |
| S6 重复 message_id 50 对 | 27.12 | 30.59 | 幂等命中 100% |
| S7 10 订阅者 fan-out ×10 | 19.91 | 21.98 | 100/100 投递 |

优化落地:**outbox 轮询 1000→200ms 后,S5 alert.push p50 835→242ms(-71%)**;S2 的按 server 批量查状态作为后续优化点记录。

## 四、工程化实践

1. **计划先行**:每个阶段先写 Develop-plans(目标/任务清单/出口条件),收口时对照检查。
2. **日志留痕**:134 篇 dev-log,每篇含日期/改动摘要/涉及文件/验证命令。
3. **Bug 闭环**:Bug-fix 四段式(现象/根因/修复/验收),README 建索引。
4. **契约纪律**:OpenAPI 唯一事实源,husky pre-commit 强制一致性检查;协议文档冻结后按版本演进。
5. **备份习惯**:重大改动前 `C:\Backup\SuSuMonitor\<timestamp>\` 备份 + 数据库 mysqldump;git 备份 remote。
6. **部署资产**:Maven Wrapper 固定 3.9.9、application-prod.yml、systemd unit、nginx 片段、install/backup/restore 脚本、运维手册 5 本。
7. **验收闭环**:每个里程碑都有真实环境验收脚本(verify-*.mjs / .ps1),并记录 PASS 证据;验收发现的问题(如 MANUAL ack 滞留)当场修复再收口。

## 五、云部署踩坑速览(详见 05 文档)

- 明文 HTTP 下 `crypto.randomUUID` 不可用 → 登录点击无反应(请求在拦截器内被同步 reject)。
- 运营商劫持明文 HTTP:剥 Upgrade 头 + 注入广告脚本 → WebSocket 400。
- 前端构建报错:`src/types/terminal.d.ts` 含运行时 const,补 `terminal.ts` 镜像并删 .d.ts。
- 分页修复:`buildQuery()` 写死 `page: 1` + `@update:page` 只赋值不 reload,两个根因。
- WSL 需 `/etc/wsl.conf` 设 `[boot] systemd=true` 才能托管 Agent。

## 六、遗留清单(诚实展示边界)

- 首管理员空库并发注册未在真实环境并发验证(实现有三重保障)。
- 多 JVM 实例部署未验证(注册表/ticket/订阅/终端中继均为单 JVM 内存态,文档已明示禁止横向扩容)。
- Monitor 慢消费者 1011 背压未在真实慢网触发(WSL loopback 下 1MiB 输出被本机 TCP 缓冲吸收,不强行制造)。
- 真实 SMTP 发送验收、真实 Agent→Java/MySQL 联合 E2E 需 DB 管理员/邮箱凭据（脚本已备）；Android approved 用户云端全链路手测待设备。
- Android 终端自研模拟器已支持 top/htop 类 TUI（光标定位/SGR 256 色/备用屏/滚动区）；vi 全指令集、DEC 私有光标样式、OSC 超链接仍为边界外。
