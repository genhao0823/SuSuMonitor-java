## 四、实现细节与参数传递

### 核心改动（`TerminalRelayLifecycleService`）

```java
public void closeAgentSessions(AgentWebSocketSession agentSession) {
    if (!agentRegistry.isCurrent(agentSession)) return;          // 被替换旧连接不触发
    for (TerminalRelayBinding binding : relayRegistry.removeByServerId(agentSession.serverId())) {
        sendClosedToMonitor(binding);                            // 新增：先向浏览器推帧
        closeBinding(binding, ERROR, "agent_disconnected");      // 原收口语义不变
    }
}
```

`sendClosedToMonitor` 生成帧字段：`type=terminal.closed`、`message_id=UUID`、`timestamp=UTC ISO-8601`（应用 Clock）、`payload{server_id, session_id, reason:"agent_disconnected"}`；浏览器 socket 已关则不推；`IOException`（含 `MonitorBackpressureException` 子类）吞掉不阻断元数据收口。
