## 一、根因修正：不是崩溃，是 vmIdleTimeout 空闲关闭

**结论**：阶段一 dev-log 中"WSL2 VM 每 1-2 分钟崩溃重启循环"的判定**有误**。Microsoft 官方文档（learn.microsoft.com/windows/wsl/wsl-config）：`.wslconfig` 的 **`vmIdleTimeout` 默认 60000 毫秒 = VM 空闲 60 秒后自动关闭**。观察到的"uptime 归零 + redis 自愈"实为：每次 wsl 命令结束后 VM 空闲 60s 自动关闭，下次命令重新启动。升级 WSL 2.7.3→2.7.11、停 dockerd、memory 限制均"无效"完全符合此解释（这些动作与 idle 关闭无关）。

**修复**：`.wslconfig` 合并重复 `[wsl2]` 段并加 `vmIdleTimeout=600000`（空闲 10 分钟才关闭）；`wsl --shutdown` 重启生效。**验证**：静置 3 分钟 uptime 保持（修复前必归零）、redis 持续在线、localhost 转发稳定。`.wslconfig` 原版备份于 `local/backup-wsl-fix/wslconfig.original`（本机配置，不进 git）。

## 四、Redis 安全加固一期

### JWT 黑名单（logout 真实失效，`3dbb7f8`）
- `JwtTokenService.ParsedToken` + `Instant expiresAt`（parseToken 已解析 expiration，补进 record）
- `security/RedisTokenBlacklist`（新，`@ConditionalOnProperty(redis.enabled=true)`）：`revoke(jti, ttl)` = `SET susumonitor:jwt-blacklist:<jti> EX ttl`；`isRevoked` = hasKey
- `JwtAuthenticationFilter`：ObjectProvider 注入（Redis 未启用时 null 安全）；parseToken 后黑名单命中 → 401（DB 回查前）；认证成功后 ParsedToken 放入 request attribute（`JWT_PARSED_TOKEN_ATTRIBUTE`）
- `AuthController.logout`：从 attribute 取 ParsedToken → `revoke(tokenId, Duration.between(now, expiresAt))`（TTL 精确到剩余有效期）；Redis 未启用时空操作（现状保持）
- 全仓测试 ParsedToken 构造批量更新（8 个测试文件）

### 登录防爆破（`9275399`）
- `AppProperties.Security`：+ `loginLimitMaxAttempts`（默认 10）/ `loginLimitWindowSeconds`（默认 60）+ yml `LOGIN_LIMIT_*`
- `ErrorCode`：+ `LOGIN_RATE_LIMIT_REACHED(42905)`
- `auth/limit/LoginRateLimiter` 接口 + `InMemoryLoginRateLimiter`（默认，固定窗口 Map）/ `RedisLoginRateLimiter`（`INCR` + 首次 `EXPIRE`，跨实例共享计数）互斥切换
- `common/ClientIpResolver`：HttpServletRequest 版，复用 `AGENT_TRUSTED_PROXY_CIDRS`，XFF 右起首个非代理（与 AgentClientIpResolver 同逻辑，入参类型不同未合并，后续可抽取）
- `AuthController.login` 开头 `checkAttempt(ip)`；`GlobalExceptionHandler` 对 42905 加 `Retry-After` 头（`@Value` 注入窗口秒数，避免 @WebMvcTest 切片缺 AppProperties bean 的问题——期间修复）

## 五、诚实边界

- 安全功能均 `REDIS_ENABLED=true` 才生效；默认 false 时 logout 空操作、login 无限流（与现状一致，过渡语义明示）
- 黑名单只记 jti（单 token 失效）；用户级失效由 DB 回查隐式覆盖（`selectAuthenticationUserById` + username 比对）
- 登录限流为**固定窗口**、按尝试次数计（成功也计数）、IP 维度（NAT 共享可能误伤）；Redis 实现 INCR+EXPIRE 两步有微小竞态（EXPIRE 幂等可接受）
- Retry-After 固定为窗口秒数（不随实际剩余时间变化）
- 本机开发环境变更留痕：MySQL 新增 `'susumonitor'@'172.26.%'` 用户（仅隔离库）；`.wslconfig` vmIdleTimeout=600000（验收友好值）；WSL 内安装 openjdk-21-jre-headless/nodejs/mysql-client；Redis 验收后已还原（bind 127.0.0.1 + protected-mode yes）
