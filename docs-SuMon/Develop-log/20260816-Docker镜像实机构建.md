## 四、期间问题与修复（留痕）

1. **compose 加载期插值阻断**（真实 bug，N6 资产从未实跑所以未暴露）：`agent` 服务（profile 门控）里的 `${SUSUMONITOR_SERVER_ID:?...}` 会让**所有** compose 命令（config/pull/build/up）在加载期报"变量缺失"。修复：改为 `:-` 空默认，运行时 fail-fast 由 agent 二进制自身校验（`getenvInt64`/`AGENT_TOKEN is required`，已验证存在）。
2. **验收脚本权限语义**：`metrics.subscribe` 用不存在的 server_id 会收到 FORBIDDEN error 帧；改为先建 server 再订阅真实 id。
3. **WSL 虚拟机周期性崩溃**（环境侧，非本项目代码）：验收期间 WSL VM 约每 2 分钟崩溃一次（Windows 事件日志无 OOM/无 Hyper-V 停机原因；主机内存 31.2GB 充足）。容器全部带 `restart: unless-stopped` + systemd 自启 dockerd，**每次自愈完整**（Flyway 幂等、健康检查恢复）——这一点客观上顺带验证了 restart 恢复能力；但首次全栈验收窗口因此多次中断，最终用"单次 WSL 会话内完成 清卷→起栈→验收→agent→收尾"的紧凑编排通过。该 VM 稳定性问题与本项目无关，后续如需稳定使用建议排查 WSL 2.7.3/Windows 26200 组合（本次未深究，如实记录）。
4. **镜像源间歇性卡顿**：daocloud 源对 maven:3.9.9-temurin-21-alpine 等大镜像反复超时，最终用"直拉+超时重试循环"逐个啃下（golang 镜像重试 3 轮）；已拉取的层会被复用。git 侧无需改动。
5. **Git Bash 引号坑**：带括号的仓库路径经 `wsl -- sh -c` 传递需转义 `\(Jvav\)`；PowerShell 单行命令中的 `$_` 会被 bash 展开（改用 .ps1 文件）。
