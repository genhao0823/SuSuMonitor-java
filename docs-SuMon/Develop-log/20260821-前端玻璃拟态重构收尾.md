## 二、改动内容

### 1. 服务器列表行为与契约

- `ServerListView` 恢复 URL query、500ms 防抖、30 秒状态刷新、卸载清理、分页回退和细分 SSH 错误提示。
- 出站参数固定为 `page/page_size/keyword/sort_by/sort_order`（keyword 与 Java Controller 及 OpenAPI 的单一模糊检索字段一致，不再发送 OpenAPI 未定义的 `name/host`）；移除错误字段 `order` 和不存在的 `error_message` 访问。
- URL 中的搜索值作为防抖 ref 初值，分页/排序在首个请求直接恢复，避免 500ms 后误把页码重置为 1。
- 新增 6 个组件回归用例，覆盖默认参数、URL 恢复、防抖、排序、末页删除和 SSH 认证错误。

### 2. 设计系统、壳层与 Dashboard

- 新增 `styles/glass.css`：中性页面基底、品牌/状态色、8px 卡片、统一阴影与 `prefers-reduced-motion`。
- 删除环境光球和 radial 装饰；PageHeader 改为无嵌套卡片的标题区，MainLayout 保留 230px 侧栏并补移动端布局。
- Dashboard 卡片改用平面分隔行，移除嵌套 `liquid-glass-subtle`；图标统一使用 Element Plus。
- 删除已备份且确认无生产引用的 `DashboardCard.vue`、`DashboardServerStatusCard.vue` 和对应 spec。
- 恢复探针“浏览器观测”文案，管理员入口迁移到独立 scoped 样式。

### 3. 列表页与视觉 QA

- 服务器/告警表格固定操作列使用实体背景，桌面滚动时不透叠。
- 768px 以下取消操作列 sticky 定位，资产/告警首列保持可见，表格内部提供横向滚动。
- 告警分页器在 640px 以下换行，避免“条/页”被卡片裁切。
- Sparkline 差值按一位小数舍入，`+20.900000000000002` 收敛为 `+20.9`，新增 1 个回归用例。

### 4. 测试与凭据安全

- UI E2E 改为运行时读取 `SUSUMONITOR_UI_E2E_BASE_URL`、`SUSUMONITOR_UI_E2E_CHROME_PATH`、
  `SUSUMONITOR_UI_E2E_ADMIN_USERNAME`、`SUSUMONITOR_UI_E2E_ADMIN_PASSWORD`。
- 管理员凭据缺失时启动浏览器前退出码为 2；日志不再输出表单值、密码长度或认证请求体。
- `auth.spec.ts` 将 `ApiBusinessError` 从测试体动态导入改为文件级静态导入；单文件耗时由约 4.2 秒降至 16–21ms，消除全量并行超时。
