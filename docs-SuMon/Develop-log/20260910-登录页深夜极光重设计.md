# 2026-09-10 登录页深夜极光重设计

**日期**：2026-09-10
**范围**：Web 前端（`web-vue-SuMon`）认证页视觉重设计，纯前端改动，无 API/路由/逻辑变更

## 一、背景

用户反馈登录页视觉不佳，先后三次迭代：

1. **参考稿复刻**（暗绛紫双栏：左插画右暗色玻璃卡）——用户反馈"好丑"，要求左侧插画改为整页背景、去掉分栏。
2. **整页插画背景 + 居中玻璃卡**——用户要求"抛弃现在所有的前端设计风格，重新设计，要好看的"。
3. **深夜极光终版**（本日志正文）——最终交付版本。

## 二、终版设计（深夜极光）

- **背景**：近黑底 `#0d0a11` + 三团大模糊光晕（玫粉 `rgba(244,63,126,0.28)` / 鎏金 `rgba(245,185,66,0.13)` / 紫罗兰 `rgba(139,92,246,0.16)`，`blur(110px)`，22-30s 仅 transform 漂移动画，`prefers-reduced-motion` 下降级）+ 极淡点阵纹理（26px 网格）。
- **卡片**：居中磨砂卡（`rgba(21,16,27,0.78)` + `blur(24px)`、20px 圆角、1px `rgba(255,255,255,0.09)` 描边、顶部 1px 高光 `rgba(255,255,255,0.14)` + 自上而下极淡白色内渐变）。
- **头像**：卡片顶部 60px 苏苏圆头像，玫粉→鎏金渐变圆环（加载失败自动隐藏，保留 OSS→本地 fallback 链）。
- **表单**：输入框左侧图标（User/Lock）、微内阴影（`inset 0 2px 4px rgba(0,0,0,0.22)`）、聚焦玫粉光圈 `#ff6b9d`；「登录/注册」按钮全宽渐变玫粉（`#ff6b9d→#f43f7e→#e0356f`）+ 光晕投影，文案去实体空格。
- **品牌**：左上角紧凑双色块 SuSu Monitor 标识 + 标语；登录卡下方一行可点击换句的苏苏引言（保留原 26+22 句引言池与键盘切换）。
- **响应式**：认证页为固定暗色视觉，不随明暗主题切换；色彩经 `--auth-*` 令牌统一由 `AuthLayout.vue` 下发。
- **旧装饰全部移除**：铃铛、飘落花瓣、波浪线、暗色纱罩、整页插画背景（组件 `SushFallingPetals.vue` 删除）。

## 四、验证证据

- **布局实测**（IAB 1280×720，DOM 度量）：登录/注册两页 `scrollHeight=720=innerHeight` 无溢出；卡片居中、与品牌区/引言无重叠；注册页（3 输入框较高）在矮视口自动隐藏引言保证一屏。
- **视觉验收**（vision-helper 两轮）：第一轮按建议补三处精修（卡片内渐变+顶高光、输入框内阴影+图标、辅助文字提亮+按钮字距）；第二轮结论"三处精修均生效，完全达到可交付水准"。
- **真实登录冒烟**：smoke 账号填表提交 → 成功跳转 `/dashboard`。
- **回归门禁**：`typecheck` / `lint`（0 警告）/ `test`（30 文件 177 用例）/ `build` 全绿。

## 五、遗留

- 无功能性遗留；认证页固定暗色为有意决策（登录页即品牌页），主站明暗主题不受影响。
- 极光动画在超低端设备上的表现未做真机专项（仅 transform 合成层动画，理论开销低）。
