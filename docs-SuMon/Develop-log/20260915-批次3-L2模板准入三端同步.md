## 二、口径决策（留痕）

1. **D3-1 替换语义统一为子串替换**：value 先过白名单正则完整匹配（拒绝元字符/空白/分号），替换后仍为单 argv 元素、不二次拆分、不经 shell——注入面不因替换方式改变；双侧渲染结果逐字一致使"人工预览=真实执行"可断言。
2. **D3-2 Go 侧不引入 risk 字段**：风险分级是 Java 审批策略概念，Agent 职责保持"白名单 + 参数校验 + 受控执行"。
3. **D3-3 默认策略不动**：`enabled=0` 保持；medium 是否放开自动审批由管理员基于批次 1 观察报告决策（产品语义不代码化）。
4. **D3-4 reload unit 正则从严**：64 长度、不含冒号（排除 device/scope 类单元），变更类入口比 L1 只读更紧。
