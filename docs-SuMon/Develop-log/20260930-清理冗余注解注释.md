- 批量删除 Java 后端紧贴注解上方的概念性行注释（复述 `@RestController`、`@NotBlank`、`@TableField`、`@Schema`、`@Test` 等注解作用的"教科书式翻译"），共删除 694 行，涉及 92 个源文件（main + test）

### 保留原则（未删除的注释类型）
- 踩坑与陷阱说明：Mapper 扫描限定（避免 sealed interface 误扫描）、springdoc 认证方案需显式声明、SpEL 循环引用规避

- 事务与安全语义：事务边界原因、只读事务与凭据列不读取、SSH 指纹格式白名单
- 配置项与字段条件语义：AppProperties 各配置项（默认值/0 值含义/cron/安全评审决策）、Entity 字段 null 语义与单位
- 测试替身原因：为什么切片测试要 mock 全局 MapperScan 注册的无关 Mapper、条件装配 Bean 缺失、跨用例计数污染；@Test 用例的中文语义说明
