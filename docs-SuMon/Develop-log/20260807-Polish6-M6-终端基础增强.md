## 一、实现

### 6a 尺寸自适应（resize 帧）
- `TerminalScreen` 用 `BoxWithConstraints` 按容器实际宽高换算 cols/rows：
  - 等宽字符宽 ≈ `14.sp × 0.6`，行高 20.dp
  - `cols = (maxWidth - 16.dp) / charWidth`（coerceIn 2..300，对齐协议上限）
  - `rows = maxHeight / lineHeight`（coerceIn 1..100）
- 首次 `open(cols, rows)` 用实际尺寸；之后尺寸变化（旋转/软键盘弹起）→ `viewModel.resize(cols, rows)`（`TerminalClient.resize` 有 OPEN 状态守卫，未 open 时安全 no-op）
- 重连按钮改用当前实际尺寸

### 6b 功能键行
- 终端顶部一行按键：Ctrl+C(`\x03`)/Ctrl+Z(`\x1a`)/Tab(`\t`)/Esc(`\x1b`)/↑(`\x1b[A`)/↓(`\x1b[B`)/←(`\x1b[D`)/→(`\x1b[C`)
- 点击 → `viewModel.sendInput(控制字节)`

### 6c 物理键盘组合键
- `SimpleTerminalView` 加 `onPreviewKeyEvent`（父级预览，先于 BasicTextField）：
  - Ctrl+A..Z → 控制字节 `0x01..0x1A`
  - Tab/Esc/方向键 → 转义序列（与功能键行一致）
- 注意：`Key` 为值类不支持 `rangeTo`，用 `keyCode in Key.A.keyCode..Key.Z.keyCode` 判断

## 二、参数传递

```
容器尺寸 → BoxWithConstraints → cols/rows
  → TerminalViewModel.open(cols, rows) / resize(cols, rows)
  → TerminalClient.open/resize → terminal.open/resize 帧 → 后端 → Agent PTY
功能键行/物理键盘 → viewModel.sendInput(ByteArray)
  → TerminalClient.sendInput → terminal.input 帧 → Agent PTY
```
