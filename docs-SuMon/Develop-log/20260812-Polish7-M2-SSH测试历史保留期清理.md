# 开发日志: SSH 测试历史保留期清理（V24 + CleanupService + Scheduler）

**日期**: 2026-08-12
**操作人**: ZCode
**阶段**: Polish-7 M2

## 背景

`ssh_test_history`（V23，2026-08-10）随每次 SSH 连接测试持续增长，无清理机制会无限膨胀。既有增长表（metrics_ingestions / message_consume_records / alert_records）已有 V22 保留期分批清理模式（`MetricsCleanup` 派生表分批 DELETE + 每批独立事务 + 运行互斥 + env 可配）。本模块将同一模式覆盖到 `ssh_test_history`，列入"增长表保留期清理"家族。

## 备份留痕

- `local/backup-polish7/m2/server-java-SuMon/src/main/resources/application.yml`（修改前备份，保留相对路径）

## 改动内容

### 后端（新增 + 修改）

- `V24__add_ssh_test_history_retention_index.sql`：为 `ssh_test_history.tested_at` 补充单列索引 `idx_ssh_test_history_tested_at`。V23 的 `(server_id, tested_at)` 复合索引无法为 tested_at 单独范围扫描服务（首列非等值），删除定位会退化为全表扫描。
- `SshTestHistoryMapper` + XML：新增 `deleteExpiredBatch(cutoffTime, batchSize)`，沿用 AlertRecordCleanupMapper 的"子查询选 id + IN 删除"模式（MySQL 8 / H2 MODE=MySQL 双兼容，避免 MySQL DELETE 直接带 ORDER BY/LIMIT 的方言差异），按 `tested_at, id` 排序取前 N。
- `SshTestHistoryCleanupService`（接口）+ `SshTestHistoryCleanupServiceImpl`：仿 `AlertRecordCleanupServiceImpl` —— cutoff = now - retentionDays（UTC）；每批独立事务（TransactionTemplate）；单轮 ≤ maxBatchesPerRun；`AtomicBoolean` 运行互斥（重叠触发返回空）；返回 `CleanupResult(cutoffTime, batchCount, deletedRows, durationMs)`（复用 MetricsCleanupService 的 record）。
- `SshTestHistoryCleanupScheduler`：`@Scheduled(cron = "${susumonitor.ssh-test-history.cleanup-cron}")` + `@ConditionalOnProperty(name = "susumonitor.ssh-test-history.cleanup-enabled", havingValue = "true")`，异常只影响当前轮次。
- `AppProperties`：新增嵌套配置类 `SshTestHistory`（retentionDays=90 / cleanupCron / cleanupEnabled=true / cleanupBatchSize=1000 / cleanupMaxBatchesPerRun=100，含 @Min/@Max/@NotBlank 校验），字段 + getter。
- `application.yml`：新增 `susumonitor.ssh-test-history.*` 五键（`${ENV:default}` 风格）：
  - `SSH_TEST_HISTORY_RETENTION_DAYS`(90)、`SSH_TEST_HISTORY_CLEANUP_CRON`(`0 0 3 * * ?`)、`SSH_TEST_HISTORY_CLEANUP_ENABLED`(true)、`SSH_TEST_HISTORY_CLEANUP_BATCH_SIZE`(1000)、`SSH_TEST_HISTORY_CLEANUP_MAX_BATCHES_PER_RUN`(100)

### 测试

- `SshTestHistoryCleanupServiceTests`（新增，3 例）：无过期数据 0 批 / 达到批次上限停止（3 批 6 行）/ 重叠触发跳过（CountDownLatch 并发）。
- `SshTestHistoryMapperMybatisTests`（扩展 +1 例）：H2 真实 XML —— 5 条混合记录按 cutoff 分批删除（limit 2 → 2 行；后续批次 → 1 行），断言仅早于 cutoff 的记录被删、新记录保留。

## 边界与说明

- 保留期默认 90 天与 alert_records 对齐；本机开发/云端均可用 env 覆盖。
- 定时清理为单 JVM 内运行互斥；多 JVM 并发清理（多实例阶段）不在本模块范围。
