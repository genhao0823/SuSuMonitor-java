### Swagger UI 公网访问修复（同日追加）

云端 `https://genhaosan.online/swagger-ui.html` 与 `/api-docs` 返回 SPA 页面，无法访问 Swagger 文档。根因为两层叠加：

1. **nginx SPA fallback 吞掉路径**：`location / { try_files $uri $uri/ /index.html; }` 使未显式代理的路径全部回退前端 index.html。
2. **Spring Security 拦截**：`SecurityConfig` 未放行 `/swagger-ui/**`、`/api-docs/**`、`/webjars/**`。

修复：`SecurityConfig.java` 新增 GET 放行行 → 重新打包部署到 `/opt/susumonitor/releases/swagger-ui-20260810/` → 云端 nginx `susumonitor.conf` 插入 4 个 swagger 代理 location（Host 设为 `genhaosan.online`）→ `nginx -s reload`。公网验证全绿（swagger-ui 200、api-docs 200、api/health 与首页回归正常）。详见 `docs-SuMon/Difficulty-log/20260810-Swagger-UI被nginx-SPA-fallback吞掉.md`。
