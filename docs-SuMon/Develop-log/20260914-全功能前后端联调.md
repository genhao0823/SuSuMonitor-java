## 三、联调发现并修复的缺陷（详见 Bug-fix/2026-09-14-*）

| # | 缺陷 | 级别 | 根因 | 修复 |
| --- | --- | --- | --- | --- |
| 1 | Agent Token 轮换必现 50001 | 高 | V35 `agent_token_hash_prev VARCHAR(64)` 装不下 71 字符摘要（Data too long） | V36 `MODIFY VARCHAR(255)` |
| 2 | 宽限期 prev 列写入新哈希（宽限失效） | 高 | MySQL UPDATE SET 从左到右求值 | 调整 SET 顺序（prev 先于 hash） |
| 3 | 未映射 API 路径返回 500/50000 | 中 | `NoHandlerFoundException`/`NoResourceFoundException` 被 Exception 兜底吞掉 | GlobalExceptionHandler 专用映射 404/40400（内网实测为 NoHandlerFound） |
| 4 | AI 个人配置更新必现 50001（数据实际已更新） | 高 | `ON DUPLICATE KEY UPDATE` found_rows 语义返回 2，`!= 1` 误判 | 改 `< 1`；回归单测 |

共同教训：**手写 SQL 的行数语义/求值顺序（D1/D2/D4）与框架信号异常（D3）均被 mock 型单测掩盖**——已为 D1/D2 补真实 MySQL IT 断言、D4 补更新路径单测、D3 补双异常单测。api-test 三脚本契约漂移同步修复（记录于 `Bug-fix/2026-09-14-api-test-stale-endpoints.md`）。
