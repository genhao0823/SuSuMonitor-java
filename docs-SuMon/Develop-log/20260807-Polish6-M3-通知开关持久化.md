**前置基线**：通知开关仅内存态（SettingsViewModel "暂存内存"注释）

## 一、实现

1. **新增 `data/SettingsRepository.kt`**（DataStore Preferences，仿 SessionStore 模式）：
   - 独立 DataStore 文件 `susumonitor_settings`，key `notifications_enabled`（默认 true）
   - `notificationsEnabled: Flow<Boolean>`、`suspend setNotificationsEnabled(Boolean)`、`suspend notificationsEnabledNow()`（同步读取，供前台服务用）
2. **SettingsViewModel**：注入 SettingsRepository；init 收集 `notificationsEnabled` 流同步 UI；`setNotificationsEnabled` 写 DataStore（替换"暂存内存"注释）
3. **MonitorForegroundService**：注入 SettingsRepository；`postAlertNotification` 在 `serviceScope` 协程里先 `notificationsEnabledNow()` 判断，开关关闭则不发布通知（事件流仍转发给 UI 横幅，两路解耦）

## 二、参数传递链

```
设置页 Switch → SettingsViewModel.setNotificationsEnabled(Boolean)
  → SettingsRepository.setNotificationsEnabled(Boolean) [DataStore edit]
  → DataStore <susumonitor_settings: notifications_enabled>

前台服务收到 alert.push
  → postAlertNotification → SettingsRepository.notificationsEnabledNow()
  → true: NotificationHelper.showAlertNotification / false: 跳过（UI 事件流不受影响）
```
