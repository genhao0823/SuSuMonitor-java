# 2026-07-29 Java 后端云服务器部署验证

## 范围

在用户授权下，将 `main` 分支最新后端部署到云服务器 `82.156.245.102`：

- 主机：OpenCloudOS 9.6 / Tencent Kona JDK 21.0.11-ga。
- 数据库：本机 MySQL 8.4，宝塔创建 `susumonitor` 数据库。

## 配置变更

1. 数据库用户密码策略临时降至 LOW，理由：宝塔创建 `susumonitor` 用户使用 `<REDACTED>`，不满足 MySQL MEDIUM 长度 8、大小写、数字、特殊字符要求。已创建：

   ```sql
   CREATE USER 'susumonitor'@'localhost' IDENTIFIED BY '<REDACTED>';
   CREATE USER 'susumonitor'@'127.0.0.1' IDENTIFIED BY '<REDACTED>';
   CREATE USER 'susumonitor'@'%' IDENTIFIED BY '<REDACTED>';
   GRANT ALL PRIVILEGES ON susumonitor.* TO 'susumonitor'@'localhost';
   GRANT ALL PRIVILEGES ON susumonitor.* TO 'susumonitor'@'127.0.0.1';
   GRANT ALL PRIVILEGES ON susumonitor.* TO 'susumonitor'@'%';
   CREATE DATABASE IF NOT EXISTS susumonitor DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

2. 生产 secret 注入到 `/etc/susumonitor/server.env`（权限 0600，root:root）。仅包含：

   - `APP_ENV=prod`
   - `DB_*` 基础连接
   - `JWT_SECRET` 标准 base64 编码
   - `AES_GCM_KEY` 标准 base64 编码
   - `AGENT_REGISTER_KEY`
   - `AGENT_TRUSTED_PROXY_CIDRS=127.0.0.1/32,::1/128`

   注意：JWT 密钥生成必须使用标准 base64（保留 `=` 填充），否则 Spring 启动时会报 `Illegal base64 character`。

3. systemd unit:

   - User=`susumonitor`
   - EnvironmentFile=`/etc/susumonitor/server.env`
   - `JAVA_TOOL_OPTIONS=-Xms256m -Xmx768m -Dfile.encoding=UTF-8`
   - 限制为 `/var/lib/susumonitor` 写权限，UMask=0077。

## 已知差距

1. **未验证 Nginx 反代**。当前云端宝塔 Nginx 默认配置没有 `/api/`、`/ws/agent`、`/ws/monitor` 反代片段；后续要按 `deploy/nginx-susumonitor.conf.example` 手工合并进 HTTPS `server` 块。
2. **未验证 WebSocket Upgrade**。`/ws/agent` 和 `/ws/monitor` 反代需要 Nginx `proxy_http_version 1.1` 和 `Upgrade/Connection upgrade` 头；当前不在本轮范围。
3. **未验证 HTTPS/WSS**。仅有 IPv4 无域名，不能做公网证书验证。
4. **未跑真实 Agent 或终端会话**。需要在 WSL 安装 Go Agent 跳 SSH 后连接 `ws://82.156.245.102/ws/agent`，本轮未做。
5. **MySQL 密码策略临时降低**。MEDIUM 策略允许短密码会带来安全风险；生产应保持 MEDIUM，并在 `server.env` 使用符合策略的密码。
6. **仅单个 deploy 单元**。`/opt/susumonitor/releases/cloud-20260729` 当前版本目录，没有保留回滚链。

## 单 JVM 限制

`TerminalSessionServiceImpl` 仅保证单 JVM 配额正确。云端当前为单实例 systemd unit，因此配额生效；如果后续横向扩展，需要重新评估。
