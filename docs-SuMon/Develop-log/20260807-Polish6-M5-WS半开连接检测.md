# 2026-08-07 Polish-6 M5：WS 半开连接检测

**状态**：完成（compile + testDebugUnitTest 全绿）
**前置基线**：nginx 空闲断开后 OkHttp 未及时感知（Android 遗留项）

## 一、实现

- `WsClient` 新增 `webSocketClient`：由注入的 `okHttpClient` 派生（`newBuilder().pingInterval(30, TimeUnit.SECONDS).build()`）
- `connectOnce()` 改用 `webSocketClient.newWebSocket(...)`
- 原理：OkHttp WebSocket 客户端每 30s 空闲时自动发 Ping 帧；nginx `proxy_read_timeout 3600s` 之下连接空闲不触发，但若链路被中间层静默断开（半开），Ping 无 Pong 响应 → OkHttp 触发 `onFailure` → 复用既有 `connectWithRetry` 指数退避重连

## 二、参数/配置

- 派生客户端不影响 REST 调用（只 WebSocket 建连用），避免全局 OkHttp 行为变更
- 周期 30s（小于服务端心跳 60s 的观测窗口，兼顾省电与感知时效）
