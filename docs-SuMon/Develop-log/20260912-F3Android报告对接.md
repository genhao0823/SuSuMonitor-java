## 二、核心逻辑说明

1. **参数传递**：列表 `GET ?page=&page_size=`（query）；详情 `GET /{id}`（path，Long）；生成 `POST body {"report_date":"YYYY-MM-DD"}`，null 字段被 AppJson 省略（出站 `{}`），由后端统一时钟取昨日——与 Web 端同语义，规避端侧时区与后端 UTC 日期边界错位。
2. **导航参数**：详情路由 `healthReportDetail/{reportId}`（NavType.LongType），与 `commandRunDetail/{runId}` 完全同构；两个路由均入 `stackRoutes` 隐藏底部导航。
3. **生成流程**：确认弹窗（覆盖语义提示）→ `generate(date)` 置 `isGenerating` 防重入 → 成功后刷新列表 + 记录 `generatedReportId` → 屏幕 `LaunchedEffect` 导航详情 → `consumeGeneratedReport()` 清除事件。
