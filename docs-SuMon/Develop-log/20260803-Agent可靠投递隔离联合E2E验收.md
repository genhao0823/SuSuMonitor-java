## 结论边界与后续

- Fixture 验证传输层 ACK 丢失、重传、重启、FIFO、容量、节流；不模拟 Java 内部事务故障。
- 真实 Java 层验证真实 Agent→Server→MySQL→ACK→spool 清理；不声称其模拟了 ACK 抑制。
- 当前不支持 `metrics.nack`、永久业务错误 dead-letter、队列字节上限与管理端积压展示；普通 Server `error` 仍安全保留队首，可能阻塞后续指标。
