## 二、核心逻辑改动

1. **触发链路**：Scheduler 直接调 Service（不经 Outbox/RabbitMQ）——触发方为服务端自身调度、报告按 report_date 唯一键天然幂等，无重放需求（决策记录见 20260911 计划文档 §二）。
2. **降级语义**：`succeeded`=含 LLM 摘要；`degraded`=仅聚合事实（summary 空、error_code 记录 50304/50303/50401/42906 等）。手动触发的限流/预算/未来日期拒绝在聚合与 provider 调用**之前**短路，保证"拒绝即无副作用"；调度路径预算耗尽时跳过模型调用直接降级，预算约束不被绕过。
3. **事后通知语义**：与 `AiAlertExplanationNotifier` 同一尽力而为语义——不落库、不重试、异常只记日志；独立 notify-enabled 开关，渠道为配置级而非按规则级。
