## 四、验收步骤与断言

执行：WSL 内

```bash
SUSUMONITOR_FLOW_SCENARIO=agent-disconnect-closed ./scripts/run-wsl-terminal-flow-control-integration.sh
```

（脚本自动用 `/opt/go` 构建 agent + 集成二进制到 `/tmp/susumonitor-terminal-flow-control/`，0700；管理员凭据经 stdin/WSLENV 注入）

场景时序与断言（`runAgentDisconnectClosed` + `expectAgentDisconnectedClose`）：

| 步骤 | 动作 | 断言 |
|---|---|---|
| 1 | 登录 → 创建隔离 server → 签发临时 Agent Token | admin/approved 校验通过 |
| 2 | 启动 WSL Agent（`TERMINAL_ENABLED=true`，`/bin/bash` PTY） | `/api/servers/{id}` 轮询 `agent_status=online` |
| 3 | 签发 Monitor Ticket → `/ws/monitor?ticket=` → 发 `terminal.open` | 收到 `terminal.opened`，取回 `session_id` |
| 4 | 杀掉 Agent 进程（SIGINT→5s→SIGKILL，`stopAgent`） | Java `afterConnectionClosed` → `closeAgentSessions` → `sendClosedToMonitor` |
| 5 | 在**同一** Monitor WS 上等待 `terminal.closed` | `message_id` 为 UUID v4；`timestamp` 为 UTC ISO-8601（RFC3339 且 `Z` 结尾）；`payload.server_id` == 目标 server；`payload.session_id` == 第 3 步会话；`payload.reason` == `agent_disconnected` |

失败出口：`TERMINAL_FLOW_CONTROL_INTEGRATION_FAILED: <固定诊断类别>`（不打印帧内容/凭据）。
