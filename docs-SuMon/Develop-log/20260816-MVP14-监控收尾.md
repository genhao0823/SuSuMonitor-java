## 三、实现细节与参数传递

### 消费统计（M2/M4）
- `ConsumeTimingInterceptor.invoke`：`adviceChain` 最外层，`System.nanoTime` 计时 → `registry.record(consumerFor(msg), durationMs)`；异常 rethrow 不吞。consumer 名经 `ConsumerQueueNames.QUEUE_TO_CONSUMER` 映射（`FailedConsumeRecordRecoverer` 同步改引用，消除重复定义）
- `ConsumeTimingStatsRegistry`：ConcurrentHashMap 窗口 `{totalCount, totalMs, maxMs, lastSampleAt}`，`snapshot()` 返回 `Map.copyOf` 不可变副本
- `ConsumeStatsService`（alert.consume 模块契约，遵守数据所有权）：`windowCounts()` 调 `countByConsumerAndStatus(status, since)`（`created_at >= since GROUP BY consumer`），failed+consumed 两路合并；键大小写归一化（H2/MySQL 标签折叠差异）
- 端点组合：`avgMs = totalMs/totalCount`；`failureRate = round(failed*10000/(failed+consumed))/10000`（窗口无记录时为 null）

### 队列积压（M3/M4）
- `QueueBacklogProbeService.probe()`：`rabbitTemplate.execute(channel -> channel.queueDeclarePassive(queue).getMessageCount())` 对 6 队列逐个执行；单队列异常 → error 快照不中断；业务队列超阈值 → `log.warn("queue backlog exceeded...")`
- `QueueBacklogProbeScheduler`：`@Scheduled(fixedDelayString = "${susumonitor.rabbitmq.queue-monitor-interval-ms:60000}")`，条件 `@ConditionalOnExpression(rabbitmq.enabled && queue-monitor-enabled)`（@ConditionalOnProperty 不可重复）
- 端点：business/dead_letter 类型划分 + warnThreshold + checkedAt + error

### 配置（application.yml，4 个新环境变量）
`ALERT_CONSUME_STATS_WINDOW_MINUTES:60` / `ALERT_QUEUE_MONITOR_ENABLED:true` / `ALERT_QUEUE_MONITOR_INTERVAL_MS:60000` / `ALERT_QUEUE_BACKLOG_WARN_THRESHOLD:10000`

## 五、实施中发现并修复的连带问题

1. **`@ConditionalOnProperty` 不可重复**：调度器初版叠两个注解 → 编译失败（并引发 Lombok 级联报错）。改为 `@ConditionalOnExpression("${rabbitmq.enabled} and ${queue-monitor-enabled}")`，同时消除了"queue-monitor-enabled 独立于 rabbitmq.enabled 导致测试上下文缺失依赖"的装配缺陷
2. **H2/MySQL 聚合标签大小写**：`GROUP BY` 结果列标签在 H2 大写折叠、MySQL 保持原样 → 聚合服务与测试统一做键归一化
3. **Mockito 嵌套 mock 限制**：`thenReturn(declareOk(...))` 在 when() 求值期间创建 mock 触发 UnfinishedStubbing → 改为预构造 DeclareOk mock 映射

## 六、验证边界（诚实声明）

- 统计为**单 JVM 内存窗口**（多实例各自统计，与项目单 JVM 口径一致）；重启清零；耗时含容器级重试整轮
- **阈值告警路径由单测覆盖**（探测服务阈值用例），真实 broker 验收未复现 backlog warn 日志（业务队列无积压时无法触发；构造积压需停消费者，超出本轮验收脚本能力）——已如实留痕
- 失败率窗口按 `created_at`（应用时钟 UTC 写入）；窗口外记录不计入
- 不实跑 cron（调度器单测覆盖 + C4 实时探测验证）；Broker 短暂不可达时探测容错（error 标记）
- 滚动升级验证（MVP-14 剩余项）需多版本部署环境，未做
