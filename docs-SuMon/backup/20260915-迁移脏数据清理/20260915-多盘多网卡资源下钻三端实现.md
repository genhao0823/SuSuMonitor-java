## 一、交付内容

复制进程快照（v1.4）的三件套模式到扩展资源：Agent 每采集周期上报**每挂载点磁盘容量**（物理分区、fstype 否定名单过滤、挂载点去重、总容量降序、≤32 条）与**分网卡吞吐**（排除 lo、采集周期差分 kbps、接收速率降序、≤64 条）；后端不入库（零 Flyway 迁移），内存注册表保留每服务器最新快照（90 秒新鲜窗口、读取侧惰性过期、无后台扫描线程），REST 暴露 + `metrics.update` 捎带可选 `resources` 节点；前端监控页新增「磁盘 / 网卡」卡片（磁盘容量条 Tab + 网卡速率 Tab）。
