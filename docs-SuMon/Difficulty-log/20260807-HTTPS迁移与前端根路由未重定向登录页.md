# 2026-08-07 HTTPS 迁移与前端根路由未重定向登录页

## 一、背景

ICP 备案管局审核通过，域名 `genhaosan.online` 获得合法备案。此前系统一直使用裸 IP 明文 HTTP（`http://82.156.245.102`）运行，现需迁移至 HTTPS/WSS。

---

## 二、问题一：访问 `https://genhaosan.online/` 不跳转登录页

### 现象

浏览器访问 `https://genhaosan.online/` 后，页面显示 MainLayout 外壳（顶栏 "SuSuMonitor"，右侧 "未登录"），主内容区为空白，**不跳转到 `/login`**。

### 根因分析

Vue Router 路由守卫（`guards.ts`）只在 `to.meta.requiresAuth === true` 时才重定向到登录页：

```typescript
// guards.ts
if (to.meta.requiresAuth === true && !auth.isAuthenticated) {
  return { name: 'login', ... }
}
```

而根路径 `/` 对应的是 `protectedLayout`（MainLayout），**该父路由没有设置 `requiresAuth`，也没有设置 `redirect`**：

```typescript
// router/index.ts（问题代码）
const protectedLayout: RouteRecordRaw = {
  path: '/',
  component: MainLayout,
  children: protectedChildren  // 无 redirect，无 requiresAuth
}
```

访问 `/` 时守卫条件不满足，只渲染了 MainLayout 空壳，子路由 `<router-view>` 为空，无任何重定向。

### 解决方案

给 `protectedLayout` 加上 `redirect: '/dashboard'`：

```typescript
// router/index.ts（修复后）
const protectedLayout: RouteRecordRaw = {
  path: '/',
  component: MainLayout,
  redirect: '/dashboard',   // ← 新增
  children: protectedChildren
}
```

**流转链路**：`/` → `/dashboard`（有 `requiresAuth: true`）→ 守卫检测到未登录 → 跳 `/login?redirect=/dashboard`

## 三、问题二：前端 build 失败——`AlertRulesView.vue` 多余 `</style>`

### 现象

执行 `npm run build` 报错：

```
SyntaxError: [plugin vite:vue] src/views/AlertRulesView.vue (367:1): Invalid end tag.
```

### 根因分析

`AlertRulesView.vue` 中 `<style scoped>` 块在第 324 行被提前错误关闭，后续 325-366 行的 CSS 游离在 `</style>` 之外，导致第 367 行出现孤立的无效 `</style>` 闭合标签：

```html
<style scoped>
.alert-rules-view__channel-tag { margin-right: 4px; }
</style>              <!-- ← 第 324 行：错误的提前关闭 -->
.alert-rules-view {   <!-- ← 游离 CSS，语法非法 -->
  ...
}
</style>              <!-- ← 第 367 行：孤立闭合标签，Invalid end tag -->
```

### 解决方案

删除第 324 行多余的 `</style>`，让样式块完整包含所有 CSS 内容直到第 367 行：

```html
<style scoped>
.alert-rules-view__channel-tag { margin-right: 4px; }
.alert-rules-view {   <!-- 所有样式统一在一个 style 块内 -->
  ...
}
</style>              <!-- 唯一的正确闭合 -->
```

## 四、HTTPS 迁移完整步骤记录

### 4.1 DNS 解析

在腾讯云 DNSPod 添加两条 A 记录：

| 主机记录 | 类型 | 值 |
|---|---|---|
| `@` | A | `82.156.245.102` |
| `www` | A | `82.156.245.102` |

### 4.2 安装 certbot 并申请证书

服务器为腾讯云 OpenCloudOS 9，Nginx 由宝塔面板安装（路径 `/www/server/nginx/`）：

```bash
dnf install -y certbot python3-certbot-nginx
certbot --nginx --nginx-server-root /www/server/nginx/conf \
  -d genhaosan.online -d www.genhaosan.online
```

证书路径：
- `/etc/letsencrypt/live/genhaosan.online/fullchain.pem`
- `/etc/letsencrypt/live/genhaosan.online/privkey.pem`
- 到期：2026-11-05，**自动续期已配置**

### 4.3 Nginx 配置更新

文件：`/www/server/panel/vhost/nginx/susumonitor.conf`

关键配置：
- HTTP 80 → HTTPS 301 重定向
- `www.genhaosan.online` → `genhaosan.online` 重定向
- HTTPS 443 + SSL + `/api/` 反代 + `/ws/agent` `/ws/monitor` WSS 反代
- `X-Forwarded-Proto: https` 透传

### 4.4 Android App 更新

文件：`app-kt-SuMon/app/src/main/java/com/susumonitor/util/Constants.kt`

```kotlin
// 修改前
const val BASE_URL = "http://82.156.245.102"
const val WS_URL   = "ws://82.156.245.102/ws/monitor"

// 修改后
const val BASE_URL = "https://genhaosan.online"
const val WS_URL   = "wss://genhaosan.online/ws/monitor"
```

同时收紧 `network_security_config.xml`：删除裸 IP 明文放行规则，全局禁止明文流量。

### 4.5 前端无需修改

前端 API 使用相对路径 `/api`，WebSocket 使用 `window.location.protocol` 自适应协议：

```typescript
// websocket.ts（无需修改）
const protocol = window.location.protocol === 'https:' ? 'wss:' : 'ws:'
this.socket = new WebSocket(`${protocol}//${window.location.host}/ws/monitor?ticket=...`)
```
