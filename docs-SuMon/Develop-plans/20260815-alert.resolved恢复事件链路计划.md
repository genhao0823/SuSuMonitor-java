1. **发布侧**：评估器 `handleResolve` 在恢复事务内——记录 `status→resolved`（resolved_at 落库，V26）→ 同事务登记 Outbox 事件 `alert.resolved.v1` + 发布本地 `AlertResolvedEvent`（AFTER_COMMIT 推 WS）

## 四、M3 事件发布层细节

### 参数传递与代码骨架

```java
// AlertResolvedEvent（module/alert/service/，对称 AlertTriggeredEvent）
public record AlertResolvedEvent(Long serverId, AlertRecordVo record) {}

// AlertResolvedEnvelopeFactory（module/alert/outbox/，对称 AlertTriggeredEnvelopeFactory）
public static final String EVENT_TYPE = "alert.resolved";
public static final String ROUTING_KEY = "alert.resolved.v1";
public static final String PRODUCER = "alert-service";
public static final int SCHEMA_VERSION = 1;
// build(AlertRecordVo record, String eventId) → 信封 JSON
// payload 8 字段（恢复语义，不含触发值）：
//   server_id / rule_id / record_id / metric / level / status(=resolved) / triggered_at / resolved_at

// 评估器 handleResolve（AlertEvaluationServiceImpl，注入 AlertResolvedEnvelopeFactory）
private void handleResolve(AlertStateEntity state) {
    LocalDateTime now = LocalDateTime.now(clock);
    int updated = recordMapper.updateStatusToResolved(state.getAlertRecordId(), now);
    if (updated == 0) {  // 记录未实际转为 resolved（缺失/已恢复）→ 不发恢复事件
        log.warn("alert resolve skipped: record already resolved or missing, recordId={}", state.getAlertRecordId());
        return;
    }
    int deleted = stateMapper.deleteState(state.getId(), state.getVersion());
    if (deleted == 0) { log.warn("alert state optimistic lock conflict during resolve, stateId={}", state.getId()); }
    AlertRecordEntity record = recordMapper.selectRecordById(state.getAlertRecordId());
    AlertRecordVo recordVo = toVo(record);
    eventPublisher.publishEvent(new AlertResolvedEvent(record.getServerId(), recordVo));
    String eventId = UUID.randomUUID().toString();
    String envelope = resolvedEnvelopeFactory.build(recordVo, eventId);
    outboxService.enqueue(AlertResolvedEnvelopeFactory.EVENT_TYPE,
            AlertResolvedEnvelopeFactory.ROUTING_KEY, envelope, eventId);
}

// AlertPushPublisher（websocket/，与 onAlertTriggered 共享私有 push(serverId, record)）
@TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
public void onAlertResolved(AlertResolvedEvent event) { push(event.serverId(), event.record()); }
// 帧：type=alert.push，payload{server_id, alert: recordVo}；record.status=resolved
```
