## 二、实现步骤与参数传递

1. **类型层** `src/types/api.d.ts`：追加 `AiHealthReportStatus`、`AiHealthReportFacts`（server_inventory/metric_peaks/alert_statistics/offline_servers 四组）、`AiHealthReport`、`GenerateHealthReportRequest`，全部 snake_case 对齐契约。
2. **API 层** 新建 `src/api/healthReport.ts`：
   - `listHealthReports({page,page_size})` → `GET /ai/health-reports?page=&page_size=`（query 传参，后端必填）
   - `getHealthReport(id)` → `GET /ai/health-reports/{id}`（40400 折叠为 `data:null`，仿 `getAlertExplanation`）
   - `generateHealthReport(req?)` → `POST /ai/health-reports/generate`，body `{report_date:'YYYY-MM-DD'}`（省略由后端取昨日，避免前端本地时区与后端 UTC 日期边界错位），`timeout:180_000`（LLM 生成 > 问答的 120s）+ `silent:true`
3. **视图层** `src/views/AiHealthReportsView.vue`：列表（状态 tag succeeded=正常/degraded=降级、摘要首行、token、耗时、生成时间）+ 分页（ServerPagination：`:page/:page-size/:total` + `@update:page/@update:page-size`）；手动生成（覆盖语义 ElMessageBox.confirm → 成功刷新并打开详情）；详情弹窗复用行数据（列表 VO 已含 facts，不再二次请求），渲染摘要/值得关注/局限说明/facts 四分组/元信息。页内 ref 状态，不建 Pinia store。
4. **路由** `/ai/reports`，name `ai-health-reports`；**菜单** MainLayout `allMenus` 追加「AI 报告」（TrendCharts 图标）。
5. **顺带修正**：菜单模板原 `:is="item.icon"`（字符串）无法解析未全局注册的图标组件，改为 `:is="iconMap[item.icon]"` 走已导入组件映射，全部菜单图标恢复渲染。
