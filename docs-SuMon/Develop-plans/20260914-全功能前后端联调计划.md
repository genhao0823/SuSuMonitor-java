## 一、环境口径（评审确认）

| 项 | 口径 |
| --- | --- |
| 被测后端 | 内网应用机（地址见机密手册）`susumonitor-server.service`，经内网 nginx 80 入口访问；按手册 §六 流程部署新 jar，部署前远端备份旧 jar，回滚预案就绪 |
| 迁移 | 现网 Flyway V34 → 新 jar 重启自动执行 V35（仅 `servers` 增列，安全） |
| 重启影响 | 3 台真实 Agent（server 8/10/11）断连数秒后自动重连；公网入口短暂 502——属预期，不操作这三台的 Token |
| 登录账号 | 管理员测试账号经环境变量运行时注入（凭据不入库不入 git，见机密手册） |
| 红线 | 不动真实 Agent Token；不改 `AES_GCM_KEY`；不碰 MC 的系统 java 17；server.env 修改前记录原值、测后恢复 |
| AI | 真实 OpenAI 兼容网关（公网 IP，可通过 deny-private 校验），Key/模型仅运行时提供；`allow-insecure-http` 已在现网开启 |
| Agent | 本地 WSL 编译真实 Go Agent，接入**新建测试服务器记录**，直连内网后端（不经公网），不影响真实 Agent |
| 浏览器 | ZCode 内置浏览器自动操作内网入口，逐页留证 |
| Redis 故障注入 | 内网机无 Redis：fail-closed/fail-open 在**本地隔离实例**（本地 MySQL + 本地 Redis + 后端 18081）补测；内网机仅验证"无 Redis 登出无状态 200"（决策二） |
