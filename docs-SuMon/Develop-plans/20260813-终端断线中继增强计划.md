### M2 Java 后端中继增强（技术栈：Java 21 / Spring Boot 3.4.7 / Spring WebSocket / Jackson）

**现状代码**（`src/main/java/com/susumonitor/server/websocket/TerminalRelayLifecycleService.java` L49-56）：

```java
public void closeAgentSessions(AgentWebSocketSession agentSession) {
    if (!agentRegistry.isCurrent(agentSession)) {
        return;
    }
    for (TerminalRelayRegistry.TerminalRelayBinding binding : relayRegistry.removeByServerId(agentSession.serverId())) {
        closeBinding(binding, TerminalSessionStatus.ERROR.value(), "agent_disconnected");
    }
}
```

**改动 1：新增私有方法 `sendClosedToMonitor(TerminalRelayBinding binding)`**（仿既有 `sendClose` L78-88 模式）：

```java
private void sendClosedToMonitor(TerminalRelayRegistry.TerminalRelayBinding binding) {
    if (!binding.monitorSession().socketSession().isOpen()) {
        return; // 浏览器已断开不推帧
    }
    String body = objectMapper.createObjectNode()
            .put("type", TerminalMessageType.TERMINAL_CLOSED.value())   // "terminal.closed"
            .put("message_id", UUID.randomUUID().toString())            // 服务端生成 UUID
            .put("timestamp", OffsetDateTime.now(clock).toString())     // UTC ISO-8601，应用 Clock 注入
            .set("payload", objectMapper.createObjectNode()
                    .put("server_id", binding.serverId())
                    .put("session_id", binding.sessionId())
                    .put("reason", "agent_disconnected"))
            .toString();
    try {
        binding.monitorSession().send(new TextMessage(body));
    } catch (IOException | MonitorBackpressureException ignored) {
        // 浏览器已断开或慢消费者背压：推送失败不阻断元数据收口
    }
}
```

**改动 2：`closeAgentSessions` 在收口前先推送**：

```java
public void closeAgentSessions(AgentWebSocketSession agentSession) {
    if (!agentRegistry.isCurrent(agentSession)) {
        return;
    }
    for (TerminalRelayRegistry.TerminalRelayBinding binding : relayRegistry.removeByServerId(agentSession.serverId())) {
        sendClosedToMonitor(binding);
        closeBinding(binding, TerminalSessionStatus.ERROR.value(), "agent_disconnected");
    }
}
```

**参数传递（帧字段 → 端侧消费映射）**：

| 帧字段 | 值 | Web 消费（`terminal-ws.ts` L211-219） | Android 消费（`TerminalClient.kt` L324-339） |
|---|---|---|---|
| `type` | `terminal.closed` | `case 'terminal.closed'` → phase=closed + `onClosed(reason)` | `handleClosed` → 展示 + 非正常原因触发重连 |
| `payload.reason` | `agent_disconnected` | `TerminalView` 显示 `[closed] agent_disconnected` | `errorMessage` 展示；`!= REASON_PROCESS_EXITED` → `scheduleReopen()` 自动重连 |
| `payload.server_id` / `session_id` | 会话归属 | 仅关联信息，会话已收口不参与后续操作 | 同左 |

**关键设计点**：
1. `removeByServerId` 返回后 binding 已从注册表移除，推送失败无残留状态；推送与收口顺序为"先推帧、后收口"，收口（`closeBinding`：移除路由 + 释放限流桶 + 持久化 ERROR）保持原语义不变
2. `isCurrent` 过滤保持：被替换的旧 Agent 连接断开不推帧（其会话已由新连接接管）
3. `MonitorBackpressureException` 需与 `IOException` 双 catch（背压场景浏览器会话即将被 1011 关闭，推送失败属预期）
4. 不修改 `TerminalMessageType`（`terminal.closed` 已存在）；不修改 `TerminalProtocolValidator`（浏览器接收 `terminal.closed` 本就是合法方向）；不修改任何配置项（无新增 env）

**测试扩展**（`src/test/java/.../TerminalRelayLifecycleServiceTests.java`，+3 用例）：

1. `closeAgentSessionsShouldNotifyMonitorWithClosedFrame`：bind(monitor-1, server 9) → `closeAgentSessions(currentAgent)` → 断言 monitor 底层 socket 收到含 `"terminal.closed"`、`"agent_disconnected"`、session_id 的 `TextMessage`，且 `closeSession(ERROR, agent_disconnected)` 照常调用
