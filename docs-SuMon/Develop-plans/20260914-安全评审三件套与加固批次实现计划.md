## 零、策略决策（2026-09-14 评审拍板）

| # | 决策点 | 结论 | 理由 |
| --- | --- | --- | --- |
| 1 | Redis 黑名单查询故障语义 | **fail-closed 默认 + `on-error` 配置开关**；专用 503 错误面（复用 `REDIS_UNAVAILABLE(50302)`） | 安全优先；现状为"碰巧 fail-closed 但错误面是误导性的数据库 500"，需显式化并保留 fail-open 运维逃生口 |
| 2 | 无 Redis 时 logout 空操作（Token 剩余有效期最长 72h 仍可用） | **文档化接受现状**，不改代码 | 当前生产 `REDIS_ENABLED=false` 为已知单实例语义；在 OpenAPI 契约与开发日志显式标注，不为单实例规模引入每请求 DB 查询 |
| 3 | AI 个人 Provider 出站（SSRF）默认策略 | **`deny-private` 默认 + `allow-private` 开关**；保存配置时与每次 LLM 调用前双重校验 | 复查原话"不能一刀切禁私网（allow-insecure-http 本为内网网关设计），需配置开关区分"；全局系统 Provider 不受限（生产可能走内网网关） |
| 4 | 本轮范围 | **三件套 + 加固批次两项**（SSH 凭据 String 驻留堆、Agent Token 轮换无宽限期） | 与三件套同在复查 §二记录，一次收口 |

读码核实前置结论（2026-09-14）：**SSH TOCTOU 在当前代码已闭合**——`SshOutboundPolicy.resolveAndValidate`（ssh/SshOutboundPolicy.java:52）单次解析并逐地址校验，`SshConnectionTester.connect`（ssh/SshConnectionTester.java:230-242）对校验后的 `InetAddress` 直连，连接阶段无二次解析；全库 SSHJ 出站仅此一处（终端经 `TerminalAgentRelayService` 走 Go Agent 中继，无 Java 直连 SSH）。故 M3 只做防御性测试与留痕确认，不重写。

## 三、验收门槛

1. 每模块独立本地 commit，提交信息符合 `feat(server)/test(server)/docs` 约定，`mvnw test` 全绿。
2. Redis 故障：fail_closed 下任意带 Token 请求收 503/50302 专用错误面；fail_open 下放行且有 warn 日志。
