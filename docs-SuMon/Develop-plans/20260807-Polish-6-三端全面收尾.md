## 四、各模块代码细节

### M2 告警通知深链
- `MainViewModel` 加 `MutableSharedFlow<Boolean> openAlertsRequest` + `fun requestOpenAlerts()`（emit true）
- `MainActivity.handleNotificationIntent`：`ACTION_OPEN_ALERTS` → `requestOpenAlerts()`
- `AppNavHost`：`LaunchedEffect` 收集事件 → 底部导航 selectedTab 切告警 Tab（index 2）

### M3 通知开关持久化
- 新增 `data/SettingsRepository.kt`（Hilt `@Singleton`，`Context.dataStore` Preferences，key `notifications_enabled` 默认 true）
- `SettingsViewModel` 注入 Repository，uiState 从 Flow 收集；`setNotificationsEnabled` 写 DataStore
- `MonitorForegroundService` 发通知前读开关

### M4 排序选择器
- `ServerListScreen` 搜索行加 `ExposedDropdownMenuBox`：排序字段（name/created_at）+ 方向（asc/desc）
- 选中调 `viewModel.onSortChange(sortBy, sortOrder)`（已有）

### M5 WS 心跳
- `WsClient` OkHttpClient builder 加 `.pingInterval(30, TimeUnit.SECONDS)`
- 空闲超时 → onFailure → 复用 `connectWithRetry`

### M6 终端增强
- 6a：TerminalScreen `BoxWithConstraints` 计算 cols/rows → `open()`/`resize()` 用实际尺寸
- 6b：功能键行按钮 → 控制字节：Ctrl+C=`\x03`、Ctrl+Z=`\x1a`、Tab=`\t`、Esc=`\x1b`、↑=`\x1b[A`、↓=`\x1b[B`、→=`\x1b[C`、←=`\x1b[D`
- 6c：SimpleTerminalView `onPreviewKeyEvent` 捕获 Ctrl+字母 → `\x01`..`\x1a`

### M8 通知历史
- 后端：`AlertNotification` 实体（已存在）+ mapper 查询 + Service + Controller `GET /api/alerts/records/{id}/notifications`；OpenApi-SuMon server JSON 同步
- 前端：`AlertRecordsView.vue` 加"通知详情"按钮 + ElDialog；`api/alerts.ts` 补接口
