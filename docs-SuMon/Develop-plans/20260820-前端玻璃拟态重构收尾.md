## 一、背景与目标

上一会话的玻璃拟态样式重构已完成约 90%，收尾前存在 3 个风险点：

1. **构建级 bug**：`ServerListView.vue` 传给 `listServers` 的字段名是 `order`，而 `ServerQuery` 类型（`src/types/api.d.ts`）只定义 `sort_order` → vue-tsc excess property check 会在 `npm run build` 直接报错。
2. **6 项功能误删**：ServerListView 在重构时被删掉了与样式无关的功能（URL 筛选同步、30s 自动刷新、防抖搜索、SSH 错误码分类提示、删除后末页回退、统一错误解释）。
3. **旧类死代码**：`DashboardAdminCard.vue` 仍用 `dashboard-view__*` 旧类；`DashboardCard.vue` 与 `DashboardServerStatusCard.vue` 是孤儿组件（无生产引用）；`DashboardView.vue` 非 scoped 块残留约 16 个旧样式类，与 liquid-* 新体系并存。

**目标**：修复 + 恢复 + 清理 + 全量验证 + 分模块提交 + 文档收口，使前端玻璃拟态重构成为健康的单一设计系统。

**边界**：本轮只做前端收尾。多实例化阶段二（注册表 Redis + WS 广播 MQ fanout）留到下一轮单独规划。无 REST API / WebSocket 协议变更，OpenAPI 与 Protocol 文档无需同步。无新增 npm 依赖。

Vue 3.5 + TypeScript 5.5 + Element Plus 2.8（@element-plus/icons-vue 2.3）+ Vite 5.4 + vue-tsc 2.1（build/typecheck 校验）+ vue-router 4.4（URL query 同步）+ pinia 3（auth store）+ axios 1.7（apiClient）+ vitest 1.6 + eslint 8.57（--max-warnings 0）+ prettier 3.3。设计系统为原生 CSS 变量 + backdrop-filter，不引入 UI 框架外依赖。

## 三、代码改动（参数传递细节）

### 模块 1：ServerListView 修复 + 功能恢复（c2）

文件：`web-vue-SuMon/src/views/ServerListView.vue`（保持当前玻璃样式不动）

- **修 bug**：`fetchServers()` 参数对象 `order:` → `sort_order:`；统一 `buildQuery(): ServerQuery` 拼参。
- **参数传递**（snake_case 出站，与 OpenAPI 对齐）：
  - `listServers(query: ServerQuery = {})`，字段 `page / page_size / sort_by / sort_order / name / host`（sort_by 白名单 `id|name|host|created_at|updated_at`，sort_order `asc|desc`）
  - `getMetricsHistory(serverId, startISO, endISO, page=1, pageSize=100)`（spark line 7 天）
  - `testSshConnection(serverId)` → `SshTestResult { connected, duration_ms, error_code, auth_type, tested_at }`
- **恢复 6 项功能**（从 HEAD `91afbba` 精确移植）：
  1. 防抖搜索：`useDebouncedRef<T>(routeQueryInitial, 500)`（`@/composables/useDebouncedRef`）；URL 搜索值在 ref 创建时恢复，`initialized` 阻止挂载阶段 watcher 双跑，保留 URL 中的原始页码。
  2. URL 同步：`syncQueryToUrl()`（`router.replace({ name: 'servers', query })`，排除默认值不留历史；query 键 `name/host/page/page_size/sort_by/sort_order`）/ `restoreQueryFromUrl()`（`route.query`，`onMounted` 最先调用一次，sort_by 白名单校验）。
  3. 30s 自动刷新：`STATUS_REFRESH_INTERVAL_MS = 30_000` + `startStatusRefresh()`（失败静默保留旧数据）+ `onBeforeUnmount` 清理定时器。
  4. SSH 错误码提示：`ApiBusinessError`（`@/api/client`）+ `ErrorCode`（`@/types/error-code`）switch，9 个 case：SSH_AUTHENTICATION_FAILED / SSH_CONNECTION_TIMEOUT / SSH_HOST_KEY_NOT_CONFIRMED / SSH_HOST_KEY_MISMATCH / SSH_TARGET_FORBIDDEN / SSH_CONNECTION_LIMIT_REACHED / SSH_CONNECTION_FAILED / FORBIDDEN / UNAUTHORIZED。
  5. 删除末页回退：`serverItems.length === 1 && page > 1` 时 `page -= 1` 再 reload。
  6. `explainError()` 统一错误解释（RESOURCE_NOT_FOUND / FORBIDDEN 分类）。
- 顺带修 SSH 列文案 `{{ row.ssh_user }}@:{{ row.ssh_port }}` 的 `@:` 连写问题。
