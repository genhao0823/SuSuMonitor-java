# 开发计划: 前端 AI 功能对接（诊断 / 问答 / 告警解释 / 命令域）

**日期**: 2026-09-09
**状态**: 已完成（历史实施计划，2026-09-09 收口；2026-09-10 追加自动审批扩展，见备注）

## 目标

将后端已实现的四大 AI 功能接入 `web-vue-SuMon` Vue3 前端，全部走既有 OpenAPI 契约
（`openapi-ai.json` / `openapi-command.json` / `openapi-alert.json`），**不修改后端**：

1. AI 只读诊断：`ServerDetailView` 操作区新增入口，弹窗展示结构化诊断结果。
2. AI 运维问答（F2）：新增 `/ai/qa` 独立页面（admin-only），本地会话式单轮问答。
3. 告警智能解释（F1）：`AlertRecordsView` 操作列新增「AI 解释」入口，弹窗回看。
4. AI 命令域（M1）：新增 `/ai/commands` 独立页面（admin-only），运行记录审批 + AI 建议/手动创建。

## 备注

- 后端请求 DTO 均 `ignoreUnknown=false`，请求体严禁携带契约外字段。
- 问答为无状态单轮接口（无 SSE/WS），前端本地维护会话历史；命令执行结果靠轮询 `GET /runs/{id}`。
- 命令域仅 L1 只读白名单模板，审批制：前端只提供 approve / reject 入口，不提供任何自由命令执行。
- **2026-09-10 扩展**（随自动审批功能一并落地，证据 `Develop-log/20260910-AI命令自动审批三端实现.md`）：
  `AiCommandsView.vue` 新增第三个「自动审批」Tab（el-switch 启用开关 + 风险阈值 radio + 保存，走
  `GET/PUT /api/ai/commands/auto-approval-policy`）；运行记录表与 AI 建议表增加风险等级 Tag 与「自动」
  审批标识；AI 建议返回非终态运行时自动启动 2s 轮询实时回填结果；`api/command.ts` 补两个策略接口
  （silent 模式）与对应 vitest 用例。
