## 三、实现细节与参数传递

### M2 compose 调优（docker-compose.yml）
- `server`：healthcheck `wget -q -O /dev/null http://127.0.0.1:18080/api/health`（`start_period: 40s` 覆盖启动+Flyway，interval 10s/timeout 5s/retries 6）；`TZ: Asia/Shanghai`（JVM 内置 tzdb 解析，清理 cron 按时区触发）；`JAVA_TOOL_OPTIONS: -XX:MaxRAMPercentage=75.0`
- `web`：healthcheck 探 `http://127.0.0.1:8080/`（nginx:1.27-alpine busybox wget）；`depends_on: server: condition: service_healthy`；`TZ: Asia/Shanghai`
- `mysql`/`rabbitmq`：加 `TZ: Asia/Shanghai`；拓扑（端口/卷/depends_on 条件/agent profile）不变
- `server-java-SuMon/Dockerfile`：`COPY --from=builder /build/target/*.jar /app/app.jar`（`*.jar` 不匹配 `.jar.original`，只拷 fat jar）；builder 加 `COPY .docker/settings.xml /root/.m2/settings.xml`
- `server-java-SuMon/.docker/settings.xml`：阿里云 central mirror（构建期专用，不进运行时镜像）
- 根 `.env.example`：必填 `MYSQL_ROOT_PASSWORD/DB_PASSWORD/RABBITMQ_PASSWORD/JWT_SECRET/AES_GCM_KEY/CORS_ALLOWED_ORIGINS`（JWT ≥32B base64、AES 恰 32B base64，`openssl rand -base64 32` 生成）；可选 `DB_NAME/DB_USER/RABBITMQ_USER/RABBITMQ_VHOST/OUTBOX_ENABLED/ALERT_NOTIFICATION_ENABLED/MAIL_*/ALERT_MAIL_FROM/AGENT_TRUSTED_PROXY_CIDRS/WEB_PORT`；agent profile：`SUSUMONITOR_SERVER_ID/SUSUMONITOR_AGENT_TOKEN/SUSUMONITOR_BACKEND_URL`；全部占位 `change-me`
