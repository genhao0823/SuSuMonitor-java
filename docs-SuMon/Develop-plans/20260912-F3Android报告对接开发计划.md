# F3 Android 报告对接开发计划

- **日期**：2026-09-12
- **范围**：`app-kt-SuMon`（Kotlin 2.0.21 + Jetpack Compose + Material3 + Retrofit + kotlinx.serialization + Hilt）
- **上游依据**：`Develop-plans/20260912-F3前端报告页对接开发计划.md` §五 优先级清单——P0 隔离库 MySQL IT 与 P1 真实渠道外发验收均被环境阻塞，取无前置依赖的 P1 Android 对接
- **契约基线**：`docs-SuMon/OpenApi-SuMon/openapi-ai.json` 0.6.0（`/api/ai/health-reports` 三端点，admin Bearer，`susumonitor.ai.report.enabled` 门控，关闭时 404）

## 一、技术栈与参数传递

| 维度 | 选型 | 备注 |
| --- | --- | --- |
| 序列化 | kotlinx.serialization `@Serializable` + `@SerialName("snake_case")`，全局 `AppJson`（ignoreUnknownKeys + encodeDefaults=false） | null 默认值字段编码时省略——`GenerateHealthReportRequest()` 出站为 `{}`，后端取昨日 |
| 网络 | Retrofit 2.11 suspend 函数 + OkHttp（读超时 120s，NetworkModule 既有配置，覆盖生成接口最坏路径，**不改超时**） | 复用既有 `AiApi` 接口，无需动 ApiModule |
| DI | Hilt：`@HiltViewModel` + `@Inject constructor`；Repository `@Singleton` 构造注入 | 零新增 Module |
| 错误语义 | `AiRepository.aiCall` 模板：404→`AiNotEnabledException`（未启用空态）、42906→`AiRateLimitedException`（中文提示） | 零新错误处理代码 |
| 列表分页 | 页码驱动（非 Paging 3）：`page/total/hasMore=page*20<total`，滚到底 `LaunchedEffect(page){loadMore()}`，`PullToRefreshBox` 下拉刷新 | 与 CommandRuns/ServerList 同机制 |

## 二、实现步骤（已完成）

1. **模型层** `data/model/AiModels.kt` 追加：`AiHealthReportStatusValues`、`AiHealthReportServerInventory/MetricPeaks/TopAlertServer/AlertStatistics/OfflineServer/Facts`、`AiHealthReport`（summary:String?、error_code:Int?、usage 复用 AiUsage）、`GenerateHealthReportRequest`。
2. **API 层** `api/AiApi.kt` 追加 3 端点：`@GET("ai/health-reports")`（`@Query page/page_size`）、`@GET("ai/health-reports/{id}")`（`@Path`）、`@POST("ai/health-reports/generate")`（`@Body`）。
3. **仓库层** `data/repository/AiRepository.kt` 追加 `listHealthReports/healthReport/generateHealthReport`。
4. **ViewModel**（新建）：`HealthReportsViewModel`（列表分页 + `generate(reportDate: String?)`：成功后刷新列表并把报告 id 写入 `generatedReportId`，屏幕消费后清除避免重复导航）；`HealthReportDetailViewModel`（`load(reportId)`）。
5. **UI**（新建）：`HealthReportsScreen`（卡片流：日期+状态徽标 succeeded=StatusOnline"正常"/degraded=StatusWarning"降级(错误码)"+摘要首行+token/耗时；"生成"弹 AlertDialog——可选日期 `^\d{4}-\d{2}-\d{2}$` 校验，留空=后端昨日）；`HealthReportDetailScreen`（状态卡+摘要+值得关注+局限说明+facts 四分组+元信息，`ValueFormatter.percent`/`TimeFormatter.formatLocal` 复用）。
6. **导航** `AppNavHost.kt`：`stackRoutes` 追加 `healthReports`、`healthReportDetail/{reportId}`（隐藏底栏）；注册两个 composable（`navArgument("reportId"){NavType.LongType}`，与 commandRunDetail 同构）。`AiQaScreen` 顶栏追加「健康报告」入口。
