## 一、目标

在现有 SuSuMonitor 服务器监控数据之上定义一个面向管理员的只读大模型诊断 MVP：管理员提交 `server_id`、问题和历史窗口，系统从白名单监控数据生成脱敏上下文，调用受控的第三方 provider，并返回可审计的结构化诊断结果。

目标包括：

- 冻结 `POST /api/ai/diagnoses` 的请求、响应、权限和错误码候选契约。
- 明确第三方 provider、数据白名单、脱敏、密钥、成本、限流、kill switch 和审计边界。
- 保证 AI 只消费监控诊断所需的只读摘要，不具备终端、SSH、命令执行、数据库写入或服务器配置修改能力。
- 为后续 Java 实现提供可验证的验收门槛，同时保留 Java 主线对最终字段和错误码的调整权。

## 二、非目标

- 不在本计划中实现 Java Controller、Service、DTO/VO、数据库表、Flyway/SQL 或第三方 provider SDK。
- 不修改 `/ws/agent`、`/ws/monitor` 的终端协议，不让 AI 直接读取或发送任何终端帧。
- 不执行 SSH 握手、命令、脚本、终端输入、服务器重启、配置变更、告警规则变更或其他写操作。
- 不把模型输出当作事实、运维指令、自动修复结果或生产变更审批。
- 不承诺 provider 可用性、模型准确率、生产成本或 RC1 发布资格。
- 不将当前 OpenAPI 计划契约视为 Java Controller 已实现；契约检查中的并行例外仅用于文档阶段。

## 三、依赖与前置条件

- RC1 单实例基线和其安全审计结论，尤其是 admin-only 终端边界、凭据不出站和现有审计/限流约定。
- 已冻结的服务器、指标、告警和认证数据语义；AI 只读取经白名单批准的字段。
- 管理员 Bearer JWT 鉴权、服务器归属/软删除校验和统一 `{ code, message, data }` 响应信封。
- provider 白名单、出站域名/网络策略、API 密钥托管、超时和重试策略。
- 脱敏规则及其 fail-closed 测试；规则未加载、字段不确定或脱敏失败时必须拒绝外发。
- 成本预算、按管理员/服务器/IP 的限流配额、全局和 provider 级 kill switch。
- Java 主线对最终 endpoint、字段命名、错误映射、模型/usage 结构的实现确认。

## 六、验收门槛

### 文档与契约门槛

- [ ] OpenAPI 3.0 JSON 可解析，所有本地 `$ref` 可解析，端点明确 `admin` Bearer，且请求/响应字段与 Java 最终实现完成对齐。
- [ ] README/索引列出 AI 契约为第 6 份 JSON，并标注 1 条 planned endpoint 不计入 Java 已实现端点。
- [ ] websocket 协议明确 `terminal.*` 仅 admin，且 AI 永不直接使用终端帧。

### 安全门槛

- [ ] 非 admin 始终得到拒绝；server_id 只能访问允许的服务器，软删除服务器不可诊断。
- [ ] provider 只能是配置白名单中的固定目标；密钥来自受控配置/secret，不进入日志、响应或 prompt。
- [ ] 数据白名单和脱敏链路任一异常均不发出 provider 请求；敏感字段和原始终端/SSH 数据零出站。
- [ ] prompt injection fixture 不得改变系统约束、产生工具调用或获得写/终端/SSH 能力。
- [ ] kill switch、预算、限流、超时和审计可通过自动化测试验证。

### 功能与可靠性门槛

- [ ] 成功响应包含全部结构化诊断字段，`limitations` 能表达数据不足、模型不确定性和“不得据此执行变更”。
- [ ] provider 超时、不可用、配置关闭、预算耗尽、脱敏失败和内部异常映射到稳定错误响应，不泄露内部细节。
- [ ] 结果可由 request_id/admin_id/server_id/prompt_version/provider/model/usage 追溯；原始敏感上下文按保留策略清理。
- [ ] 仅在 Java 主线实现、测试、当前 commit 和隔离/真实环境证据均具备后，才可记录“AI MVP 验收通过”；该记录仍不等同于 RC1 生产验收。

### 验收门槛与开放项决议

- 功能/可靠性门槛中"稳定错误响应"一条需按当前行为重新解读：`50303/50304/50401/50305` 在 MVP 中**默认转为 HTTP 200 确定性降级**（`model_used=false`），错误码写入审计；`42906` 与参数/权限错误直接返回。已同步到 `openapi-ai.json` 响应说明。
- 开放项决议：`history_minutes` 必填、0–1440、允许 0（等价"仅最新"）；`question` 1–4000 字符 + 关键词策略（无语言/字符集白名单）；`model_used` 为布尔；`usage` 含 input/output/total tokens 与 `estimated_cost`（provider 未回传成本时恒 0，仅 token 计数）；`provider`/`model` 为服务端配置原样展示。
- 未变的前提：AI 默认关闭；启用需显式 `AI_ENABLED=true` + HTTPS endpoint + key + model；启动不校验 key 有效性，首次调用才知道。
